# ПРОТОКОЛ: ПЕРЕЗАПУСК

Многопользовательская браузерная командная игра.

## Требования
- Node.js 18 или новее
- ОС Windows/Linux/macOS

## Установка
1. Склонируйте репозиторий.
2. Выполните \`npm install\` в корне проекта.
3. Скопируйте \`.env.example\` в \`.env\` и настройте пароль ведущего.

## Запуск в production
Выполните \`npm run build && node server/dist/index.js\`.
Или на Windows используйте \`start.bat\`.

## Адреса экранов
- Регистрация: \`http://<ВАШ_IP>:3000/\`
- Экран ведущего: \`http://<ВАШ_IP>:3000/host\`
- Общий экран: \`http://<ВАШ_IP>:3000/display\`
- Терминал: \`http://<ВАШ_IP>:3000/terminal\`
