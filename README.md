# ПРОТОКОЛ: ПЕРЕЗАПУСК

Многопользовательская браузерная командная игра.

## Требования
- Node.js 18 или новее
- ОС Windows/Linux/macOS

## Установка и первый запуск
1. Установите зависимости (выполните из корня проекта):
   `npm install`
2. Создайте локальную конфигурацию:
   `cp .env.example .env`
   *(Укажите свой `HOST_PASSWORD` в файле `.env`)*
3. Соберите проект:
   `npm run build`
4. Запустите сервер (база данных SQLite `game.db` инициализируется автоматически):
   `npm start`
   На Windows вы можете использовать скрипт `start.bat`. На macOS/Linux можно использовать `start.sh`.

## Адреса и порядок открытия
Откройте браузер по адресу `http://localhost:3000` (или укажите ваш локальный IP-адрес для других устройств в локальной сети).

1. **Панель ведущего:** `http://<IP>:3000/host`
   - Введите пароль из `.env`.
   - Ожидайте регистрацию игроков. По завершению нажмите "Распределить команды", затем переходите к "Следующий этап".
2. **Общий экран:** `http://<IP>:3000/display`
   - Выведите на интерактивную доску или проектор.
3. **Регистрация игрока:** `http://<IP>:3000/` или `http://<IP>:3000/join`
   - Игроки заходят со своих смартфонов, вводят имя.
   - После этого они попадают в лобби и ожидают распределения.
4. **Командные терминалы:** `http://<IP>:3000/terminal`
   - Откройте на двух стационарных компьютерах (для двух команд).
   - Введите код привязки, чтобы закрепить терминал за командой (сейчас это тестовая заглушка).
5. **История:** `http://<IP>:3000/history`
   - Для просмотра завершённых игр (доступно из панели ведущего).

## Проверки и ограничения
- **Выполненные тесты:**
  - `cd server && npx vitest run src` (модульные тесты серверной логики 1-5 раундов, пройдено 7/7).
  - `cd tests && npx playwright test` (End-to-End тесты регистрации пользователя и открытия главной страницы, 2/2 пройдено).
- **Ограничения (Заглушки и TODO):**
  - Игра интерактивна, и переходы осуществляются сервером. Тем не менее, привязка `registerTerminal` в `ROUND_3` является частичной заглушкой (терминалы получают общий бродкаст).
  - Полноценная привязка текущей сессии через `localStorage` в клиенте не завершена. Отключение сокетов или обновление страницы (F5) во время активного раунда может потребовать перерегистрации, если игрок отключился надолго.
  - Банк карточек для `ROUND_4` представлен в демонстрационном виде (не 24 карточки).
  - Автоматическое вычитание оставшегося времени из `ROUND_1`-`ROUND_5` не визуализировано полностью на телефонах, хотя штрафные таймеры блокируют интерфейсы.
