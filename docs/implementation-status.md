# Статус реализации

| Требование | Состояние до доработки | Что изменено | Как проверено |
| :--- | :--- | :--- | :--- |
| **Раунд 1** (Доставить ядро) | Заглушка. | Реализован интерфейс сетки 7x7, стрелки управления, кнопка очистки и отправки. Сервер проверяет логику движения и обновляет лучший счет. | Ручное тестирование компонентов и E2E тесты. |
| **Раунд 2** (Netwalk) | Заглушка. | Интерактивная сетка 5x5 с вращением узлов (отрисовка линий). | Отрисовка компонентов. |
| **Раунд 3** (Аварийный доступ) | Заглушка. | На терминале есть выбор 4-х из 6-ти модулей. На телефонах выводятся подсказки. | UI проверки. |
| **Раунд 4** (Карантин) | Заглушка. | Интерфейс карточки с выбором "Разрешить"/"Заблокировать" и выводом объяснений. | UI проверки. |
| **Раунд 5** (Согласованный запуск) | Заглушка. | Вывод графовой зависимости, таймер блокировки при преждевременном клике. | UI проверки. |
| **Общий экран** | Заглушка. | Рендерит статус игры, лобби, размеры команд, события. | UI проверки. |
| **Терминал** | Заглушка. | Экран привязки по коду. Во время Раунда 3 показывает UI модулей. | UI проверки. |
| **Игровой процесс** | Базовая. | Настроены пробросы событий socket.io от клиента к серверу. Реализована обработка. Маршрутизация через express SPA fallback исправлена | E2E + Unit тесты. |
